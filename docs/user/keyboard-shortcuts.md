# Keyboard shortcuts

> On Windows/Linux, use <kbd>Ctrl</kbd> wherever <kbd>⌘</kbd> is shown.

## General

| Action | Shortcut |
| --- | --- |
| Command palette | <kbd>⌘K</kbd> |
| Toggle catalog | <kbd>C</kbd> |
| Help & shortcuts | <kbd>?</kbd> |
| 2D ⇄ 3D floor plan | <kbd>P</kbd> |

## View & camera

| Action | Shortcut |
| --- | --- |
| Walk / orbit | <kbd>V</kbd> |
| Top‑down view | <kbd>O</kbd> |
| Reset view | <kbd>H</kbd> |
| Time of day | <kbd>T</kbd> |
| Measurements | <kbd>M</kbd> |
| Tidy room | <kbd>L</kbd> |
| Select / orbit tool | <kbd>G</kbd> |

## Editing a selection

| Action | Shortcut |
| --- | --- |
| Rotate (90° · 15°) | <kbd>R</kbd> · <kbd>Shift</kbd>+<kbd>R</kbd> |
| Flip | <kbd>F</kbd> |
| Duplicate | <kbd>⌘D</kbd> |
| Copy / paste | <kbd>⌘C</kbd> / <kbd>⌘V</kbd> |
| Nudge (fine) | arrow keys (<kbd>Shift</kbd> = fine) |
| Delete | <kbd>Del</kbd> |
| Deselect | <kbd>Esc</kbd> |
| Undo / redo | <kbd>⌘Z</kbd> / <kbd>⌘Y</kbd> (or <kbd>Shift</kbd>+<kbd>⌘Z</kbd>) |

## In walk mode

| Action | Shortcut |
| --- | --- |
| Move | <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> |
| Look around | click the scene, then move the mouse |
| Release the mouse | <kbd>Esc</kbd> |
| Open / close a door | <kbd>E</kbd> |
| Back to orbit | <kbd>V</kbd> |

> On touch devices there's no keyboard: use the on‑screen joystick to move and
> drag the scene to look around. See [Navigating the flat](/navigating#walk-mode).

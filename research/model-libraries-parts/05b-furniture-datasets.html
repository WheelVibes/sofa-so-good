3D-FUTURE (Alibaba Homestyler)

URLtianchi.aliyun.com/.../alibaba-3d-future · toolbox github.com/3D-FRONT-FUTURE
License3D-FUTURE Terms of Use (research-oriented; email + signed ToU). Commercial use NOT granted by the ToU — FLAG as research/dev-only.
Asset types & formats9,992 unique industrial CAD furniture meshes with high-res designer textures + attributes (category/style/theme). OBJ + texture maps. Furniture-specific — the most directly relevant dataset.
Programmatic accessRequest via email (3dfront@list.alibaba-inc.com) + attach signed ToU → 3 download links (3D-FRONT house / 3D-FUTURE furniture / textures). Not open, but bulk once approved.
Render qualityhigh — professional designer textures on real industrial furniture CAD.
NotesPairs with 3D-FRONT scenes. Best-fit furniture dataset; license blocks shipping (R&D/eval only).

ABO — Amazon Berkeley Objects

URLamazon-berkeley-objects.s3.amazonaws.com · AWS Open Data
LicenseCC BY-NC 4.0 — non-commercial only. FLAG (research/eval, not shippable).
Asset types & formats147,702 product listings + metadata; 7,953 high-quality 3D models as glTF 2.0 (.glb) (real Amazon furniture/home products) + 398k catalog images, 360° spins. CSV/JSON metadata.
Programmatic accessOpen S3 bucket bulk download, no form. glTF/GLB is web-ready (Three.js-native).
Render qualityhigh — real product CAD, glTF 2.0.
NotesExcellent format fit (GLB) + open download, but NC license blocks commercial shipping.

Google Scanned Objects ✅ (commercial-safe)

URLresearch.google — Scanned Objects (on Gazebo/Fuel)
LicenseCC-BY 4.0 — commercial use OK with attribution. One of the few clean-commercial scanned sets.
Asset types & formats1,030 scanned common household items (~13GB): OBJ + texture PNG (collision meshes too; GLB/SDF via Gazebo). Some furniture/decor/houseware.
Programmatic accessOpen bulk download (Gazebo Fuel API / mirrors), no form.
Render qualityhigh — clean professional scans with textures.
NotesCommercial-safe + good quality; limited furniture count but usable. Strong pick.

Objaverse 1.0 / Objaverse-XL (Allen AI)

URLobjaverse.allenai.org · HF: allenai/objaverse-xl
LicenseCollection under ODC-By v1.0; each object carries its own Creative Commons license in the metadata — must filter per-object (CC0/CC-BY usable; CC-NC/SA restricted) for commercial use.
Asset types & formatsObjaverse 1.0 = ~800K 3D objects; Objaverse-XL = 10M+. GLB/GLTF + others (sourced from Sketchfab, GitHub, Thingiverse, etc.). Huge furniture/prop coverage.
Programmatic accessPython API + HuggingFace — fully scriptable bulk download with per-object metadata (license, tags) for filtering. The most accessible large-scale set.
Render qualitymedium — extremely variable (community-sourced): low-poly → high; filter by quality/license.
NotesBest scale + programmatic access; commercial use requires per-object CC filtering (metadata makes this feasible).

3D-FRONT (furnished rooms)

URLtianchi.aliyun.com/dataset/65347 · arxiv 2011.09127
LicenseAlibaba terms; reported CC BY-NC 4.0 — non-commercial. FLAG.
Asset types & formats~18,797 professionally-designed furnished ROOMS/houses with layouts + semantics, furnished using 3D-FUTURE meshes. JSON scene layouts (assets come from 3D-FUTURE).
Programmatic accessEmail/request (same channel as 3D-FUTURE); BlenderProc loader exists.
Render qualitymedium — value is in LAYOUTS/scene composition, not new assets.
NotesGoldmine for realistic room LAYOUT priors (auto-arrange/training), not separable furniture. Non-commercial.

ShapeNet (Core / Sem)

URLshapenet.org · HF mirror
LicenseShapeNet Terms — non-commercial research/education only (registration + admin approval). FLAG.
Asset types & formatsShapeNetCore ~51K models / 55 categories (incl. chair/sofa/table/bed/cabinet — strong furniture); ShapeNetSem ~12K richly annotated. OBJ + materials (often untextured/simple).
Programmatic accessRegistered download (HF mirror for approved users). Bulk once approved.
Render qualitylow→medium — CAD geometry, many untextured/low-fidelity; great for shape, weak for photoreal.
NotesThe classic furniture shape benchmark; non-commercial; needs texturing for realism.

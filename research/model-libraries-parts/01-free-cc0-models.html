Poly Pizza

URLhttps://poly.pizza/
LicenseMostly CC0 and CC-BY (per-asset; license shown on each model page). Successor to the discontinued Google Poly low-poly archive.
Asset types & formatsLow-poly props, furniture, decor, characters, food, vehicles. Download as GLB (also GLTF). Direct web-ready models, no login to download.
Programmatic accessAPI (REST) — documented at poly.pizza/docs/api/v1.1. Requires a free API key (free for hobby, pay-as-you-go for commercial). List/search endpoints return a Download field with a direct CDN GLB URL (e.g. https://static.poly.pizza/<uid>.glb) — trivially scriptable for batch fetch. Predictable static CDN URLs.
Render qualitymedium — clean game-ready low-poly with flat/vertex colours; tidy topology, but stylized rather than PBR-photoreal. Many untextured (low) up to lightly textured (medium).
NotesStrong furniture/interior coverage (chairs, tables, sofas, lamps, kitchen). GLB is ideal for Three.js/@react-three/fiber. CC-BY items need attribution; CC0 items don't. CC-BY-eligible for prod (CORS-friendly CDN). Catalog: thousands of models.

Quaternius

URLhttps://quaternius.com/
LicenseCC0 (public domain) for all packs — commercial use, no attribution required (donations encouraged).
Asset types & formatsThemed low-poly packs incl. furniture/interior (Modular houses, kitchen, household props), nature, characters (rigged/animated), vehicles. Formats: GLTF/GLB, FBX, OBJ, BLEND.
Programmatic accessManual / bulk per-pack ZIP download from the site (also mirrored via itch.io and Patreon). No public REST API; packs are downloadable as predictable ZIP bundles per collection — scriptable if you enumerate pack URLs, but no official index API.
Render qualitymedium — consistent, well-made low-poly game art; mostly flat/gradient materials, no PBR detail. Excellent for stylized scenes, not photoreal.
NotesVery consistent art style across packs — good for a cohesive stylized interior set. CC0 = safe to bundle in prod with no attribution. Thousands of assets across dozens of packs.

Kenney (kenney.nl)

URLhttps://kenney.nl/assets
LicenseCC0 — all assets public domain, commercial use, no attribution required.
Asset types & formats40k+ CC0 game assets. 3D packs incl. "Furniture Kit", "Kitchen Kit", "City Kit", "House" / interior props, modular building blocks. Formats: GLB/GLTF, FBX, OBJ (and Blender source); packs as ZIP.
Programmatic accessBulk download — per-pack ZIPs with stable URLs on kenney.nl (and an itch.io mirror). No REST API, but ZIP URLs are predictable and the whole catalog can be bulk-fetched ("Kenney Game Assets" all-in-one bundle). Project already references Kenney zip handling as dev-gated.
Render qualitymedium — clean, uniform low-poly modular kits with simple flat materials; not PBR/photoreal but highly composable.
NotesThe "Furniture Kit" and "Kitchen Kit" are directly interior-relevant and modular (snap-together). CC0 means prod-safe. Per CLAUDE.md the Kenney zip pipeline is treated as a dev-only sidecar in this repo.

Sketchfab (CC0 / downloadable filter)

URLhttps://sketchfab.com/3d-models?features=downloadable (CC0 filter)
LicenseMixed per-asset: CC0, CC-BY, CC-BY-SA, CC-BY-NC, etc. Filterable by license. 800k+ free downloadable models; over 1M total.
Asset types & formatsEverything incl. abundant furniture/interior/decor and scanned objects. Download formats: glTF, GLB, USDZ (plus original source where uploader provides).
Programmatic accessDownload API (REST): GET https://api.sketchfab.com/v3/models/{UID}/download returns temporary signed URLs (gltf/glb/usdz). Requires OAuth/API-token auth; search via /v3/search?type=models&downloadable=true&licenses=cc0. Fully scriptable for batch with auth. Rate-limited; download links expire.
Render qualityultra (mixed) — ranges from low hobby uploads to ultra photoscanned/film-grade. Quality is per-asset; curate by license + face count + texture.
NotesLargest single source for furniture/decor variety; also hosts Smithsonian + many museum CC0 scans. Watch licenses (NC excludes commercial). Attribution required for CC-BY/-SA. Auth requirement complicates anonymous client-side use; better to pre-download server-side.

BlenderKit (free tier)

URLhttps://www.blenderkit.com/
LicenseMixed: many free assets are CC0 or Royalty-Free (RF); per-asset license shown. 10k+ free models (63k+ total free assets incl. materials/HDRIs).
Asset types & formatsStrong furniture/interior catalog (kitchen sets, sofas, faucets, appliances, storage). Native BLEND; can export GLB/GLTF/FBX/OBJ via Blender. Web search/browse without login.
Programmatic accessPrimary access is the Blender add-on (open-source on GitHub: BlenderKit/BlenderKit) which calls a private REST backend with an API key. Scriptable through the add-on's API client, but not a clean public download API; practically you fetch into Blender then export. Not direct GLB-by-URL for web.
Render qualitymedium-to-high — many archviz-grade PBR furniture models; quality varies by contributor. Treat as medium baseline with high outliers.
NotesBest fit when a Blender-export pipeline exists (convert BLEND→GLB). License is per-asset — must filter for CC0/RF + check commercial terms before bundling. Large, interior-focused catalog.
